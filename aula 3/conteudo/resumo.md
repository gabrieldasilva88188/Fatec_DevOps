
**Conceitos Principais**

* **O Problema de Configuração:** O desafio de garantir alinhamento em equipes de desenvolvimento para evitar erros clássicos do tipo *"na minha máquina funciona"* devido a variações em versões de código, bibliotecas, bancos de dados e variáveis de ambiente.


* **Definição e Itens de Configuração:** Configuração abrange todos os dados que regem o comportamento de um sistema. Os itens incluem código fonte (`.js`, `.java`), gerenciadores de dependências (`package.json`, `pom.xml`), arquivos de parâmetros (`.env`, `YAML`), banco de dados, infraestrutura (`Docker`, `Terraform`) e documentação.


* **Ambiente Node.js & NPM:** Apresenta o Node.js como ambiente de execução JavaScript no servidor e o NPM como gerenciador automatizado de dependências via arquivo `package.json`.



**Prática e Ferramentas**

* **Projetos React:** Instruções de inicialização com `npx create-react-app`, detalhando scripts básicos (`npm start`), pastas fundamentais (`node_modules`, `public`, `src`) e papéis de arquivos centrais (`index.js`, `App.js`).


* **Uso de Templates e Atividade:** Aponta repositórios como GitHub, Vercel e CodeSandbox para reutilização de modelos. A aula encerra solicitando a importação, alteração e deploy de um template React na Vercel com documentação no GitHub.
