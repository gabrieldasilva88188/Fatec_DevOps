---

## ✨ Funcionalidades e Destaques

- 🎭 **Cena 3D Interativa:** Renderização gráfica em tempo real no navegador.
- 👆 **Controle de Câmera (OrbitControls):** Permite rotacionar e dar zoom na cena via mouse/touch.
- ⚡ **Desempenho Otimizado:** Desenvolvido com **Vite** e **@playcanvas/react** para carregamento rápido e leve.

---

## 🛠️ Tecnologias Utilizadas

- **[React](https://react.dev/):** Biblioteca principal para interface do usuário.
- **[@playcanvas/react](https://github.com/playcanvas/react):** Wrapper React para o engine 3D PlayCanvas.
- **[Vite](https://vitejs.dev/):** Ferramenta de build rápida para o desenvolvimento frontend.
- **[Vercel](https://vercel.com/):** Plataforma de hospedagem e contínuo deploy.
